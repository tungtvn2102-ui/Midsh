## PvE 3D World (Three.js)

Fresh rebuild at repository root.

### Run

- Start a local server in this folder and open `http://localhost:8002/`:

```
# Option A: Node (if installed)
npx --yes serve -s -l 8002 .
# Option B: Python (if installed)
python -m http.server 8002
```

- Then click Play in the page.

### Controls

- W/A/S/D: Move
- Mouse: Look
- Left click: Shoot
- Space: Jump
- ESC: Unlock mouse/pause
